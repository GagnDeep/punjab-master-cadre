Module B • Lesson 04

Indefinite Integrals

Objectives

  • Understand integration as an anti-derivative.
  • Memorize the integrals of standard functions.
  • Master Integration by Substitution.
  • Apply the Integration by Parts formula with ILATE.

The Golden Rule

Never forget the constant of integration!

+ C

Standard Forms

  • ∫xn dx = xn+1/(n+1) + C
  • ∫(1/x) dx = ln|x| + C
  • ∫ex dx = ex + C

Trig Integrals

  • ∫cos(x) dx = sin(x) + C
  • ∫sin(x) dx = -cos(x) + C
  • ∫sec2(x) dx = tan(x) + C

Substitution

Used when you see a function AND its derivative in the integrand.

Let u = inner function, find du, substitute.

Integration by Parts

∫u dv = uv - ∫v du

Used for products of unrelated functions.

The ILATE Rule

How to choose 'u' for Integration by Parts. Choose the first one that appears in this list:

  • Inverse Trigonometric
  • Logarithmic
  • Algebraic
  • Trigonometric
  • Exponential

Worked Example

Q: Evaluate ∫x cos(x2) dx

  • Let u = x2, so du = 2x dx → x dx = du/2
  • Sub: ∫cos(u) (du/2) = (1/2)∫cos(u) du
  • Integrate: (1/2)sin(u) + C
  • Sub back: (1/2)sin(x2) + C

Exam Trick

Memorize this pattern:

∫ex[f(x) + f'(x)]dx = exf(x) + C

Quick Review

  • Integration reverses differentiation.
  • Always add + C.
  • Substitution: Look for f(g(x))*g'(x).
  • Parts: ∫u dv = uv - ∫v du. Use ILATE.
