Module B • Lesson 03

Applications of Derivatives

Objectives

  • Find equations of tangent and normal lines.
  • Identify local maxima and minima.
  • Solve rate-of-change word problems.
  • Understand increasing and decreasing functions.

Tangents & Normals

The derivative f'(x) is the slope m of the tangent line.

Tangent Eq: y - y1 = m(x - x1)

Normal Eq: y - y1 = -1/m(x - x1)

Rate of Change

Derivatives represent how one variable changes relative to another (e.g., dy/dx, or dV/dt for volume over time).

Critical Points

Points where f'(x) = 0 or is undefined.

These are the "peaks" and "valleys" of the graph.

Second Derivative Test

At a critical point x = c (where f'(c) = 0):

  • If f''(c) > 0, the curve is concave UP → Local Minimum.
  • If f''(c) < 0, the curve is concave DOWN → Local Maximum.
  • If f''(c) = 0, the test is inconclusive.

Worked Example

Q: Find the local extrema of f(x) = x3 - 3x + 2.

  • f'(x) = 3x2 - 3. Set to 0 → x = 1, x = -1.
  • f''(x) = 6x.
  • Test x=1: f''(1) = 6 > 0 (Minimum).
  • Test x=-1: f''(-1) = -6 < 0 (Maximum).

Solution

Max at x=-1 (val=4), Min at x=1 (val=0)

Exam Strategy

For optimization word problems, always reduce the main equation to ONE variable before differentiating.

Common Trap

Forgetting to check the endpoints of a closed interval when looking for Absolute Maximum/Minimum.

Quick Review

  • Tangent slope = f'(x). Normal slope = -1/f'(x).
  • Find critical points: f'(x) = 0.
  • Use f''(x) to classify as max (-) or min (+).
