Limits & Continuity

Objectives

  • Grasp the epsilon-delta intuition of limits.
  • Evaluate standard limits efficiently.
  • Master L'Hôpital's Rule for indeterminate forms.
  • Identify removable, jump, and infinite discontinuities.
  • Define continuity at a point rigorously.

What is a Limit?

A limit describes the value a function approaches as the input approaches a specific value.

Formal Definition: For every ε > 0, there exists a δ > 0 such that if 0 < |x - a| < δ, then |f(x) - L| < ε.

Continuity

A function is continuous at x = a if:

  • f(a) is defined
  • lim(x→a) f(x) exists
  • lim(x→a) f(x) = f(a)

Types of Discontinuity

  • Removable: Limit exists, but f(a) is undefined or different.
  • Jump: LHL ≠ RHL.
  • Infinite: Asymptotes.

Standard Limits

Memorize these for the exam:

  • lim(x→0) sin(x)/x = 1
  • lim(x→0) tan(x)/x = 1
  • lim(x→0) (ex - 1)/x = 1

Why?

They allow you to bypass tedious L'Hôpital applications in complex fractions.

Worked Example

Q: Evaluate lim(x→2) (x2 - 4)/(x - 2)

Steps:

  • Direct sub: 0/0.
  • Factor numerator: (x - 2)(x + 2).
  • Cancel (x - 2) term.
  • Evaluate lim(x→2) (x + 2) = 4.

Solution

4

Exam Pattern

ERB loves functions with modulus like f(x) = |x| / x. They ask for LHL and RHL at x=0.

PYQ Focus

Remember LHL = -1, RHL = 1. Since LHL ≠ RHL, the limit does not exist (Jump discontinuity).

Quick Review

  • Limit: The value a function approaches.
  • Continuity: LHL = RHL = f(a).
  • 0/0 or ∞/∞ forms? Use L'Hôpital's Rule.
  • Standard Limit: lim(x→0) sin(x)/x = 1
