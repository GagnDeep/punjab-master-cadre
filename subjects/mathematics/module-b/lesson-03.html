Lesson 03: Applications of Derivatives

ਡੈਰੀਵੇਟਿਵਜ਼ ਦੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ (Applications of Derivatives)

Why this matters (ERB Pattern)

This is where calculus meets the real world. Questions on finding the maximum area, minimum cost, or the equation of a normal line appear in almost every ERB exam. Maximizing/minimizing problems carry high weightage.

ਇਹ ਉਹ ਥਾਂ ਹੈ ਜਿੱਥੇ ਕੈਲਕੂਲਸ ਅਸਲ ਸੰਸਾਰ ਨੂੰ ਮਿਲਦਾ ਹੈ। ਵੱਧ ਤੋਂ ਵੱਧ ਖੇਤਰ, ਘੱਟੋ-ਘੱਟ ਲਾਗਤ, ਜਾਂ ਇੱਕ ਆਮ ਰੇਖਾ ਦਾ ਸਮੀਕਰਨ ਲੱਭਣ ਬਾਰੇ ਸਵਾਲ ਲਗਭਗ ਹਰ ERB ਪ੍ਰੀਖਿਆ ਵਿੱਚ ਆਉਂਦੇ ਹਨ।

By the end of this lesson, you will:

  • Find equations of tangent and normal lines to a curve.
  • Identify local maxima and minima using the First and Second Derivative Tests.
  • Solve practical rate-of-change word problems.
  • Understand increasing and decreasing functions.

Core Concepts and Exam Focus

The derivative f'(x) gives the slope of the tangent line to the curve y = f(x) at any point x. If you have the point (x&sub1;, y&sub1;) and the slope m = f'(x&sub1;), the equation of the tangent is y - y&sub1; = m(x - x&sub1;). The normal line is perpendicular to the tangent, so its slope is -1/m.

One of the most powerful applications is finding Maxima and Minima. A function has a critical point where f'(x) = 0 or is undefined. To determine if this point is a maximum, minimum, or point of inflection, we use the Second Derivative Test: if f''(x) > 0 at the critical point, it's a local minimum (the curve is concave up, shaped like a 'U'). If f''(x) < 0, it's a local maximum (concave down, shaped like an inverted 'U').

Finally, derivatives represent the Rate of Change. If you are given a spherical balloon inflating, the rate of change of volume with respect to time (dV/dt) can be linked to the rate of change of radius (dr/dt) using the Chain Rule. Always identify what is given and what needs to be found before differentiating the relating equation with respect to time.

Worked Example

Q: Find the local maximum and minimum values of f(x) = x3 - 3x + 2.

Step 1: Find the first derivative to locate critical points: f'(x) = 3x2 - 3.

Step 2: Set f'(x) = 0: 3(x2 - 1) = 0 ⇒ x = 1, x = -1.

Step 3: Find the second derivative to test these points: f''(x) = 6x.

Step 4: Test x = 1: f''(1) = 6(1) = 6 > 0. Since it's positive, x = 1 is a local minimum. The minimum value is f(1) = 1 - 3 + 2 = 0.

Step 5: Test x = -1: f''(-1) = 6(-1) = -6 < 0. Since it's negative, x = -1 is a local maximum. The maximum value is f(-1) = -1 - 3(-1) + 2 = 4.

Answer: Local Max value is 4 (at x=-1), Local Min value is 0 (at x=1).

🧠 How ERB Asks It

Word problems are common. "A wire of length L is cut into two pieces, one bent into a square, the other a circle. Find the lengths to minimize total area." The trick is setting up the primary equation (Area) in terms of a single variable using the secondary equation (Length).

Quick Recap

  • Tangent slope m = f'(x). Normal slope = -1/m.
  • Critical points happen where f'(x) = 0.
  • Max: f''(x) < 0 (Concave down).
  • Min: f''(x) > 0 (Concave up).

Punjabi Transcript / ਪੰਜਾਬੀ ਅਨੁਵਾਦ

ਹੈਲੋ ਸਟੂਡੈਂਟਸ! ਅੱਜ ਅਸੀਂ ਡੈਰੀਵੇਟਿਵਜ਼ ਨੂੰ ਅਸਲ ਜ਼ਿੰਦਗੀ ਵਿੱਚ ਵਰਤਣਾ ਸਿੱਖਾਂਗੇ। ਹੁਣ ਤੱਕ ਅਸੀਂ ਸਿਰਫ਼ ਸਮੀਕਰਨਾਂ ਨੂੰ ਹੱਲ ਕੀਤਾ ਹੈ, ਪਰ ਅੱਜ ਅਸੀਂ ਦੇਖਾਂਗੇ ਕਿ ਡੈਰੀਵੇਟਿਵਜ਼ ਨਾਲ ਅਸੀਂ ਕਿਵੇਂ ਵੱਧ ਤੋਂ ਵੱਧ (Maximum) ਅਤੇ ਘੱਟੋ-ਘੱਟ (Minimum) ਵੈਲਿਊਜ਼ ਲੱਭ ਸਕਦੇ ਹਾਂ। ਮਾਸਟਰ ਕਾਡਰ ਦੇ ਪੇਪਰ ਵਿੱਚ ਇਸ ਟੌਪਿਕ ਵਿੱਚੋਂ ਹਮੇਸ਼ਾ ਇੱਕ ਜਾਂ ਦੋ ਸਵਾਲ ਆਉਂਦੇ ਹਨ।

ਸਭ ਤੋਂ ਪਹਿਲਾਂ ਗੱਲ ਕਰਦੇ ਹਾਂ ਟੈਂਜੈਂਟ (Tangent) ਅਤੇ ਨੋਰਮਲ (Normal) ਬਾਰੇ। ਟੈਂਜੈਂਟ ਇੱਕ ਅਜਿਹੀ ਲਾਈਨ ਹੈ ਜੋ ਕਿਸੇ ਕਰਵ (curve) ਨੂੰ ਸਿਰਫ਼ ਇੱਕ ਬਿੰਦੂ 'ਤੇ ਛੂੰਹਦੀ ਹੈ। ਡੈਰੀਵੇਟਿਵ, ਯਾਨੀ ਕਿ dy/dx, ਸਾਨੂੰ ਉਸ ਟੈਂਜੈਂਟ ਦਾ ਢਲਾਨ (slope) ਦੱਸਦਾ ਹੈ। ਜੇਕਰ ਸਾਨੂੰ ਢਲਾਨ (m) ਅਤੇ ਬਿੰਦੂ (x1, y1) ਪਤਾ ਹੈ, ਤਾਂ ਅਸੀਂ ਲਾਈਨ ਦੀ ਸਮੀਕਰਨ (y - y1) = m(x - x1) ਲਿਖ ਸਕਦੇ ਹਾਂ। ਨੋਰਮਲ ਲਾਈਨ, ਟੈਂਜੈਂਟ ਦੇ ਬਿਲਕੁਲ ਲੰਬਵਤ (perpendicular) ਹੁੰਦੀ ਹੈ, ਇਸਲਈ ਇਸਦਾ ਢਲਾਨ -1/m ਹੁੰਦਾ ਹੈ।

ਹੁਣ ਸਭ ਤੋਂ ਦਿਲਚਸਪ ਹਿੱਸਾ—ਮੈਕਸਿਮਾ (Maxima) ਅਤੇ ਮਿਨੀਮਾ (Minima)। ਸੋਚੋ ਕਿ ਤੁਸੀਂ ਇੱਕ ਪਹਾੜੀ 'ਤੇ ਚੜ੍ਹ ਰਹੇ ਹੋ। ਜਦੋਂ ਤੁਸੀਂ ਬਿਲਕੁਲ ਚੋਟੀ 'ਤੇ ਪਹੁੰਚਦੇ ਹੋ, ਤਾਂ ਜ਼ਮੀਨ ਬਿਲਕੁਲ ਸਿੱਧੀ ਹੋ ਜਾਂਦੀ ਹੈ, ਠੀਕ ਹੈ ਨਾ? ਇਸੇ ਤਰ੍ਹਾਂ, ਕਰਵ ਦੇ ਸਭ ਤੋਂ ਉੱਚੇ ਜਾਂ ਸਭ ਤੋਂ ਹੇਠਲੇ ਬਿੰਦੂ 'ਤੇ, ਟੈਂਜੈਂਟ ਲਾਈਨ ਸਿੱਧੀ ਲੇਟਵੀਂ (horizontal) ਹੋ ਜਾਂਦੀ ਹੈ, ਜਿਸਦਾ ਮਤਲਬ ਹੈ ਕਿ ਉੱਥੇ ਢਲਾਨ, ਯਾਨੀ ਕਿ f'(x), ਜ਼ੀਰੋ ਹੋਵੇਗਾ! ਇਨ੍ਹਾਂ ਬਿੰਦੂਆਂ ਨੂੰ ਕ੍ਰਿਟੀਕਲ ਪੁਆਇੰਟ (Critical Points) ਕਹਿੰਦੇ ਹਨ।

ਪਰ ਸਾਨੂੰ ਕਿਵੇਂ ਪਤਾ ਲੱਗੇਗਾ ਕਿ ਇਹ ਬਿੰਦੂ ਪਹਾੜੀ ਦੀ ਚੋਟੀ (Maximum) ਹੈ ਜਾਂ ਖੱਡ ਦਾ ਤਲ (Minimum)? ਇਸਦੇ ਲਈ ਅਸੀਂ ਸੈਕਿੰਡ ਡੈਰੀਵੇਟਿਵ ਟੈਸਟ (Second Derivative Test) ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਾਂ। ਅਸੀਂ f''(x) ਕੱਢਦੇ ਹਾਂ। ਜੇਕਰ f''(x) ਪਲੱਸ (Positive) ਵਿੱਚ ਆਵੇ, ਤਾਂ ਇਸਦਾ ਮਤਲਬ ਕਰਵ ਉੱਪਰ ਵੱਲ ਖੁੱਲ੍ਹ ਰਿਹਾ ਹੈ (U ਸ਼ੇਪ), ਯਾਨੀ ਕਿ ਇਹ ਇੱਕ ਮਿਨੀਮਮ ਬਿੰਦੂ ਹੈ। ਜੇਕਰ f''(x) ਮਾਈਨਸ (Negative) ਵਿੱਚ ਆਵੇ, ਤਾਂ ਕਰਵ ਹੇਠਾਂ ਵੱਲ ਖੁੱਲ੍ਹ ਰਿਹਾ ਹੈ (ਉਲਟਾ U), ਯਾਨੀ ਕਿ ਇਹ ਇੱਕ ਮੈਕਸਿਮਮ ਬਿੰਦੂ ਹੈ। ਯਾਦ ਰੱਖਣਾ, ਪਲੱਸ ਮਤਲਬ ਮਿਨੀਮਮ, ਮਾਈਨਸ ਮਤਲਬ ਮੈਕਸਿਮਮ!

ਇਸ ਤੋਂ ਇਲਾਵਾ, ਡੈਰੀਵੇਟਿਵਜ਼ ਨੂੰ "ਰੇਟ ਆਫ਼ ਚੇਂਜ" (Rate of Change) ਲੱਭਣ ਲਈ ਵੀ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ। ਮੰਨ ਲਓ ਇੱਕ ਗੁਬਾਰੇ ਵਿੱਚ ਹਵਾ ਭਰੀ ਜਾ ਰਹੀ ਹੈ। ਗੁਬਾਰੇ ਦਾ ਆਕਾਰ (Volume) ਕਿੰਨੀ ਤੇਜ਼ੀ ਨਾਲ ਵੱਧ ਰਿਹਾ ਹੈ? ਇਹ dV/dt ਹੈ। ਅਜਿਹੇ ਸਵਾਲਾਂ ਵਿੱਚ ਸਾਨੂੰ ਇੱਕ ਫਾਰਮੂਲਾ (ਜਿਵੇਂ ਕਿ ਗੋਲੇ ਦੇ ਆਕਾਰ ਦਾ ਫਾਰਮੂਲਾ) ਲੈਣਾ ਹੁੰਦਾ ਹੈ ਅਤੇ ਸਮੇਂ (t) ਦੇ ਹਿਸਾਬ ਨਾਲ ਉਸਦਾ ਡੈਰੀਵੇਟਿਵ ਕੱਢਣਾ ਹੁੰਦਾ ਹੈ, ਜਿੱਥੇ ਚੇਨ ਰੂਲ ਸਾਡੀ ਮਦਦ ਕਰਦਾ ਹੈ। ਇਨ੍ਹਾਂ ਸਵਾਲਾਂ ਦੀ ਚੰਗੀ ਤਰ੍ਹਾਂ ਪ੍ਰੈਕਟਿਸ ਕਰੋ, ਕਿਉਂਕਿ ਇਹ ਪੇਪਰ ਵਿੱਚ ਪੱਕਾ ਆਉਣਗੇ!

ਦੋਸਤੋ, ਐਪਲੀਕੇਸ਼ਨਜ਼ ਆਫ਼ ਡੈਰੀਵੇਟਿਵਜ਼ ਸਿਰਫ਼ ਇੱਕ ਚੈਪਟਰ ਨਹੀਂ ਹੈ, ਇਹ ਇੱਕ ਕਲਾ ਹੈ। ਜਦੋਂ ਅਸੀਂ ਕਿਸੇ ਚੀਜ਼ ਦੀ ਵੱਧ ਤੋਂ ਵੱਧ ਜਾਂ ਘੱਟੋ-ਘੱਟ ਵੈਲਿਊ ਲੱਭਦੇ ਹਾਂ, ਤਾਂ ਅਸੀਂ ਅਸਲ ਵਿੱਚ ਉਸ ਸਿਸਟਮ ਨੂੰ ਅਨੁਕੂਲ (optimize) ਕਰ ਰਹੇ ਹੁੰਦੇ ਹਾਂ। ਉਦਾਹਰਨ ਵਜੋਂ, ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਕੰਪਨੀ ਚਲਾ ਰਹੇ ਹੋ ਅਤੇ ਤੁਸੀਂ ਆਪਣਾ ਮੁਨਾਫ਼ਾ (profit) ਵਧਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ ਮੁਨਾਫ਼ੇ ਦੀ ਸਮੀਕਰਨ ਬਣਾ ਕੇ ਉਸਦਾ ਡੈਰੀਵੇਟਿਵ ਜ਼ੀਰੋ ਦੇ ਬਰਾਬਰ ਰੱਖਣਾ ਪਵੇਗਾ। ਇਹ ਸਿੱਧਾ-ਸਿੱਧਾ ਗਣਿਤ ਦੀ ਤਾਕਤ ਹੈ! ਇਸਦੇ ਨਾਲ ਹੀ, ਇਨਕਰੀਜ਼ਿੰਗ (Increasing) ਅਤੇ ਡਿਕਰੀਜ਼ਿੰਗ (Decreasing) ਫੰਕਸ਼ਨਾਂ ਦਾ ਕੰਸੈਪਟ ਵੀ ਬਹੁਤ ਅਹਿਮ ਹੈ। ਜੇਕਰ f'(x) ਪੋਜ਼ੀਟਿਵ (positive) ਹੈ, ਤਾਂ ਗ੍ਰਾਫ਼ ਉੱਪਰ ਵੱਲ ਜਾ ਰਿਹਾ ਹੈ, ਅਤੇ ਜੇਕਰ ਨੈਗੇਟਿਵ (negative) ਹੈ, ਤਾਂ ਗ੍ਰਾਫ਼ ਹੇਠਾਂ ਵੱਲ ਆ ਰਿਹਾ ਹੈ। ਇਹ ਬਿਲਕੁਲ ਸਟਾਕ ਮਾਰਕੀਟ (stock market) ਦੀ ਤਰ੍ਹਾਂ ਹੈ! ਪੇਪਰ ਵਿੱਚ ਕਈ ਵਾਰ ਇਹ ਵੀ ਪੁੱਛਿਆ ਜਾਂਦਾ ਹੈ ਕਿ ਇੱਕ ਖਾਸ ਅੰਤਰਾਲ (interval) ਵਿੱਚ ਫੰਕਸ਼ਨ ਦਾ ਸੁਭਾਅ ਕਿਹੋ ਜਿਹਾ ਹੈ। ਇਸਦੇ ਲਈ, ਕ੍ਰਿਟੀਕਲ ਪੁਆਇੰਟਸ (critical points) ਲੱਭੋ ਅਤੇ ਇੱਕ ਨੰਬਰ ਲਾਈਨ (number line) ਬਣਾਓ। ਫਿਰ ਹਰ ਹਿੱਸੇ ਵਿੱਚ f'(x) ਦਾ ਨਿਸ਼ਾਨ (sign) ਚੈੱਕ ਕਰੋ। ਇਹ ਤਰੀਕਾ ਕਦੇ ਵੀ ਗਲਤ ਨਹੀਂ ਹੁੰਦਾ। ਇਸ ਤੋਂ ਇਲਾਵਾ, ਰੇਟ ਆਫ਼ ਚੇਂਜ ਦੇ ਸਵਾਲਾਂ ਵਿੱਚ, ਹਮੇਸ਼ਾ ਧਿਆਨ ਨਾਲ ਦੇਖੋ ਕਿ ਕਿਹੜੀਆਂ ਚੀਜ਼ਾਂ ਬਦਲ ਰਹੀਆਂ ਹਨ ਅਤੇ ਕਿਹੜੀਆਂ ਸਥਿਰ (constant) ਹਨ। ਜੋ ਚੀਜ਼ ਸਥਿਰ ਹੈ, ਉਸਦਾ ਡੈਰੀਵੇਟਿਵ ਜ਼ੀਰੋ ਹੋਵੇਗਾ। ਇਹ ਛੋਟੀਆਂ-ਛੋਟੀਆਂ ਗੱਲਾਂ ਹੀ ਤੁਹਾਨੂੰ ਦੂਜੇ ਬੱਚਿਆਂ ਤੋਂ ਅੱਗੇ ਲੈ ਕੇ ਜਾਣਗੀਆਂ। ਪੂਰੇ ਵਿਸ਼ਵਾਸ ਨਾਲ ਤਿਆਰੀ ਕਰੋ ਅਤੇ ਹਰ ਕੰਸੈਪਟ ਨੂੰ ਮਜ਼ਬੂਤ ਕਰੋ।
