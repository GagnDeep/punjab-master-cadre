Lesson 01: Sets, Relations & Functions

ਸੈੱਟ, ਸੰਬੰਧ ਅਤੇ ਫੰਕਸ਼ਨ

Why this matters (ERB 2022 Pattern)

Questions on subset definitions and power sets appear almost every year. In ERB 2022, a direct question on the cardinality of a power set was asked. Knowing the basics saves time and helps you score quickly without long calculations. It is a fundamental topic.

ਪਾਵਰ ਸੈੱਟਾਂ ਬਾਰੇ ਸਵਾਲ ਹਰ ਸਾਲ ਆਉਂਦੇ ਹਨ। ERB 2022 ਵਿੱਚ, ਪਾਵਰ ਸੈੱਟ ਦੀ ਗਿਣਤੀ 'ਤੇ ਸਿੱਧਾ ਸਵਾਲ ਪੁੱਛਿਆ ਗਿਆ ਸੀ। ਬੁਨਿਆਦੀ ਗੱਲਾਂ ਜਾਣਨਾ ਸਮਾਂ ਬਚਾਉਂਦਾ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ ਲੰਬੀ ਗਣਨਾ ਦੇ ਬਿਨਾਂ ਜਲਦੀ ਸਕੋਰ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ।

By the end of this lesson, you will:

  • Define sets, subsets, and power sets clearly.
  • Understand set operations: union, intersection, difference, and complement.
  • Calculate the number of elements in subsets quickly using powers of 2.
  • Apply De Morgan's Laws to complex set operations.
  • Identify infinite vs finite sets easily.

Core Concepts and Exam Focus

A set is a well-defined collection of distinct objects. It is the most basic building block in algebra. Sets are usually denoted by capital letters like A, B, C. A subset contains elements that are all present in another set. If every element of set A is also in set B, then A is a subset of B. The power set is the set of all possible subsets. For example, the empty set is a subset of every set, and every set is a subset of itself. The cardinality of a power set is extremely important. If a set has n elements, its power set will have 2n elements. Understanding this relationship is key to solving ERB questions quickly. Set operations such as union (combining elements) and intersection (finding common elements) are also frequently tested. Remember that intersection is commutative, meaning A intersection B is the same as B intersection A. We also use Venn diagrams to visually represent these operations, which can be very helpful for complex problems.

When dealing with more advanced problems, you must be comfortable with De Morgan's Laws. These laws state that the complement of the union of two sets is the intersection of their complements, and the complement of the intersection is the union of their complements. Expressed mathematically, (A ∪ B)' = A' ∩ B' and (A ∩ B)' = A' ∪ B'. These are invaluable for simplifying complex logical expressions that appear in the reasoning sections of the exam.

Another area where students frequently lose marks is the distinction between finite, infinite, countable, and uncountable sets. A set is finite if its elements can be counted and the process comes to an end. The set of natural numbers is infinite but countable. However, the set of all real numbers between 0 and 1 is uncountable. While the Master Cadre exam usually focuses on finite sets, understanding these definitions prevents you from falling for trick options.

Furthermore, the concept of a Universal set is critical. The Universal set, typically denoted by U or epsilon, is the set that contains all objects under consideration. The complement of a set A, denoted A', contains all elements in U that are NOT in A. Therefore, A ∪ A' = U and A ∩ A' = the empty set. Memorize these identities.

Let's also discuss the Cartesian product of two sets, A x B. This is the set of all ordered pairs (a, b) where 'a' is in A and 'b' is in B. If set A has m elements and set B has n elements, the Cartesian product A x B has m * n elements. This leads directly into our next topic: Relations. A relation from A to B is simply a subset of the Cartesian product A x B. Therefore, the total number of possible relations from a set with m elements to a set with n elements is 2mn. This specific formula is tested frequently, so commit it to memory.

To excel, you must practice shading Venn diagrams for expressions like (A - B) ∪ (B - A), which represents the symmetric difference. The symmetric difference contains elements in A or B, but not in both. Knowing the visual representation allows you to quickly identify the correct formula among multiple choices without writing out lengthy proofs.

Worked Example

Q: If a set A has 5 elements, how many proper subsets does it have?

Step 1: Identify the number of elements: n = 5.

Step 2: Apply the formula for the number of subsets: 2n.

Step 3: Calculate the total subsets: 25 = 32.

Step 4: Recall that proper subsets exclude the set itself.

Step 5: Subtract 1 from the total subsets: 32 - 1 = 31.

Answer: 31 proper subsets.

🧠 How ERB Asks It

They often ask for the number of proper subsets instead of total subsets to test your attention to detail. The formula for proper subsets is 2n- 1.

Quick Recap

  • Set: Well-defined collection of distinct elements.
  • Subset: Elements inside another set.
  • Power Set Cardinality: 2n
  • Proper Subsets: 2n - 1
  • Union combines, Intersection finds commonalities.
