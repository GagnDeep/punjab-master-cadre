Lesson 03: Matrices & Operations

ਮੈਟ੍ਰਿਕਸ ਅਤੇ ਕਾਰਵਾਈਆਂ

Why this matters (ERB 2022 Pattern)

Questions involving matrix multiplication and transpose properties are frequent. Finding A squared or A cubed efficiently is a common calculation task that tests both accuracy and speed.

ਮੈਟ੍ਰਿਕਸ ਗੁਣਾ ਅਤੇ ਟ੍ਰਾਂਸਪੋਜ਼ ਦੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਾਲੇ ਸਵਾਲ ਅਕਸਰ ਆਉਂਦੇ ਹਨ। A ਵਰਗ ਜਾਂ A ਘਣ ਨੂੰ ਕੁਸ਼ਲਤਾ ਨਾਲ ਲੱਭਣਾ ਇੱਕ ਆਮ ਗਣਨਾ ਕਾਰਜ ਹੈ।

By the end of this lesson, you will:

  • Perform matrix addition, subtraction, and multiplication flawlessly.
  • Understand the concept of matrix transpose.
  • Identify symmetric and skew-symmetric matrices.
  • Apply properties of matrix operations to simplify complex expressions.
  • Decompose a square matrix into symmetric and skew-symmetric parts.

Core Concepts and Exam Focus

Matrix multiplication is fundamentally different from regular number multiplication. To multiply two matrices A (size m by n) and B (size n by p), the number of columns in A must strictly equal the number of rows in B. The resulting matrix will have the size m by p. Unlike normal numbers, matrix multiplication is not commutative, meaning AB does not generally equal BA. The transpose of a matrix, denoted as AT, is found by swapping rows and columns. A matrix is perfectly symmetric if A = AT, and it is skew-symmetric if A = -AT. Any square matrix can uniquely be expressed as the sum of a symmetric and a skew-symmetric matrix.

The algebra of matrices includes addition, subtraction, and scalar multiplication, which behave exactly as you would expect intuitively. You add corresponding elements. However, the non-commutative nature of multiplication means that expanding algebraic identities requires caution. For example, (A + B)2 is NOT A2 + 2AB + B2. It is actually A2 + AB + BA + B2. Only if A and B commute (i.e., AB = BA) does the standard binomial expansion hold. Examiners frequently exploit this misconception.

Special matrices are highly scoring if you know their properties. A diagonal matrix has non-zero elements only on the main diagonal. Multiplying diagonal matrices is simple: just multiply the corresponding diagonal elements. The Identity matrix (I) is a diagonal matrix with 1s on the diagonal. A scalar matrix is a diagonal matrix where all diagonal elements are identical.

Orthogonal matrices are another crucial concept. A matrix A is orthogonal if A * AT = I. This implies that the transpose of the matrix is equal to its inverse. The determinant of an orthogonal matrix is always +1 or -1, representing rotations and reflections in space.

Trace of a matrix is the sum of its main diagonal elements. It possesses neat properties: Trace(A+B) = Trace(A) + Trace(B), and most importantly, Trace(AB) = Trace(BA). This cyclical property is useful for proving complex identities without computing the full matrix product.

Nilpotent matrices (Ak = 0 for some integer k) and Idempotent matrices (A2 = A) often appear in multiple-choice questions requiring you to calculate high powers of A. For an idempotent matrix, A100 is simply A. Recognizing these patterns saves immense calculation time.

Worked Example

Q: If A = [[1, 2], [3, 4]] and B = [[2, 0], [1, 2]], find the element in the first row and first column of the product AB.

Step 1: Identify the first row of A: [1, 2].

Step 2: Identify the first column of B: [2, 1].

Step 3: Multiply corresponding elements and sum them up.

Step 4: Calculation: (1 * 2) + (2 * 1) = 2 + 2 = 4.

Answer: The element is 4.

🧠 How ERB Asks It

They frequently ask to decompose a square matrix into the sum of a symmetric and a skew-symmetric matrix. The standard formula to memorize is: A = 1/2(A + AT) + 1/2(A - AT).

Quick Recap

  • Inner dimensions must match for multiplication (n = n).
  • Matrix multiplication is NOT commutative (AB != BA).
  • Transpose reversal rule: (AB)T = BT AT.
  • Symmetric: A = AT.
  • Skew-symmetric: A = -AT.

ਵਿਦਿਆਰਥੀਓ, ਅੱਜ ਅਸੀਂ ਮੈਟ੍ਰਿਕਸ (Matrices) ਬਾਰੇ ਗੱਲ ਕਰਾਂਗੇ। ਮਾਸਟਰ ਕਾਡਰ ਵਿੱਚ ਇਹ ਇੱਕ ਬਹੁਤ ਹੀ ਸਕੋਰਿੰਗ ਵਿਸ਼ਾ ਹੈ, ਪਰ ਗਲਤੀਆਂ ਵੀ ਇੱਥੇ ਹੀ ਹੁੰਦੀਆਂ ਹਨ!

ਮੈਟ੍ਰਿਕਸ ਗੁਣਾ ਕਰਨਾ ਥੋੜ੍ਹਾ ਧਿਆਨ ਮੰਗਦਾ ਹੈ। ਯਾਦ ਰੱਖੋ, ਪਹਿਲੇ ਮੈਟ੍ਰਿਕਸ ਦੀਆਂ ਕਤਾਰਾਂ (Rows) ਨੂੰ ਦੂਜੇ ਮੈਟ੍ਰਿਕਸ ਦੇ ਕਾਲਮਾਂ (Columns) ਨਾਲ ਗੁਣਾ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਕਾਹਲੀ ਵਿੱਚ ਕਦੇ ਵੀ ਰੋਅ ਨੂੰ ਰੋਅ ਨਾਲ ਗੁਣਾ ਨਾ ਕਰ ਦੇਣਾ। ਅਤੇ ਸਭ ਤੋਂ ਵੱਡੀ ਗੱਲ, AB ਅਤੇ BA ਹਮੇਸ਼ਾ ਬਰਾਬਰ ਨਹੀਂ ਹੁੰਦੇ। ਗਣਿਤ ਵਿੱਚ ਅਸੀਂ 2 ਗੁਣਾ 3 ਨੂੰ 6 ਲਿਖਦੇ ਹਾਂ ਅਤੇ 3 ਗੁਣਾ 2 ਨੂੰ ਵੀ 6, ਪਰ ਮੈਟ੍ਰਿਕਸ ਵਿੱਚ ਅਜਿਹਾ ਨਹੀਂ ਹੈ!

ਦੂਜੀ ਅਹਿਮ ਗੱਲ ਹੈ Symmetric ਅਤੇ Skew-Symmetric ਮੈਟ੍ਰਿਕਸ। ਇਹਨਾਂ ਦੀ ਪਛਾਣ ਟ੍ਰਾਂਸਪੋਜ਼ (Transpose) ਤੋਂ ਹੁੰਦੀ ਹੈ। ਟ੍ਰਾਂਸਪੋਜ਼ ਦਾ ਮਤਲਬ ਹੈ ਲੇਟਵੀਆਂ ਲਾਈਨਾਂ ਨੂੰ ਖੜ੍ਹੀਆਂ ਲਾਈਨਾਂ ਬਣਾ ਦੇਣਾ। ਜੇਕਰ ਕਿਸੇ ਮੈਟ੍ਰਿਕਸ ਦਾ ਟ੍ਰਾਂਸਪੋਜ਼ ਕਰਨ ਤੋਂ ਬਾਅਦ ਵੀ ਉਹ ਬਿਲਕੁਲ ਉਹੀ ਰਹਿੰਦਾ ਹੈ, ਤਾਂ ਉਹ Symmetric ਹੈ। ਪਰ ਜੇਕਰ ਉਹ ਆਪਣੇ ਨਕਾਰਾਤਮਕ (negative) ਦੇ ਬਰਾਬਰ ਹੋ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਉਹ Skew-Symmetric ਹੈ।

ਇੱਕ ਬਹੁਤ ਹੀ ਖਾਸ ਫਾਰਮੂਲਾ ਜੋ ਪੇਪਰ ਵਿੱਚ ਵਾਰ-ਵਾਰ ਆਉਂਦਾ ਹੈ, ਉਹ ਹੈ ਟ੍ਰਾਂਸਪੋਜ਼ ਦਾ ਰਿਵਰਸਲ ਰੂਲ: (AB) ਦਾ ਟ੍ਰਾਂਸਪੋਜ਼ ਬਰਾਬਰ ਹੁੰਦਾ ਹੈ B ਦਾ ਟ੍ਰਾਂਸਪੋਜ਼ ਗੁਣਾ A ਦਾ ਟ੍ਰਾਂਸਪੋਜ਼। ਇਸਨੂੰ ਕਦੇ ਨਾ ਭੁੱਲਣਾ!

ਨਾਲ ਹੀ, ਸਾਨੂੰ ਆਈਡੈਂਟਿਟੀ ਮੈਟ੍ਰਿਕਸ (Identity Matrix) ਬਾਰੇ ਵੀ ਪਤਾ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ। ਇਹ ਮੈਟ੍ਰਿਕਸ ਗੁਣਾ ਵਿੱਚ ਨੰਬਰ '1' ਵਾਂਗ ਕੰਮ ਕਰਦਾ ਹੈ। ਕਿਸੇ ਵੀ ਮੈਟ੍ਰਿਕਸ ਨੂੰ ਇਸ ਨਾਲ ਗੁਣਾ ਕਰੋ, ਉਹੀ ਮੈਟ੍ਰਿਕਸ ਵਾਪਸ ਆ ਜਾਵੇਗਾ।

ਟ੍ਰੇਸ (Trace) ਕੱਢਣਾ ਵੀ ਬਹੁਤ ਆਸਾਨ ਹੈ। ਬਸ ਮੁੱਖ ਡਾਇਗਨਲ (main diagonal) ਦੇ ਸਾਰੇ ਅੰਕਾਂ ਨੂੰ ਜੋੜ ਦਿਓ। ਪੇਪਰ ਵਿੱਚ ਕਈ ਵਾਰ ਉਹ AB ਦਾ ਟ੍ਰੇਸ ਪੁੱਛਦੇ ਹਨ, ਤਾਂ ਯਾਦ ਰੱਖੋ Trace(AB) ਬਰਾਬਰ ਹੁੰਦਾ ਹੈ Trace(BA) ਦੇ। ਇਹਨਾਂ ਛੋਟੇ-ਛੋਟੇ ਨਿਯਮਾਂ ਨਾਲ ਤੁਸੀਂ ਵੱਡੇ ਸਵਾਲਾਂ ਨੂੰ ਸਕਿੰਟਾਂ ਵਿੱਚ ਹੱਲ ਕਰ ਸਕਦੇ ਹੋ!
