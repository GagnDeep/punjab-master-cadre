Module A • Lesson 02

Types of Relations & Functions

Objectives

  • Identify reflexive, symmetric, and transitive relations with ease.
  • Understand the concept of an equivalence relation.
  • Define one-to-one (injective) and onto (surjective) functions.
  • Determine if a function is bijective by checking both conditions.
  • Calculate composite functions quickly.

Core Concept

A relation R on a set A is an equivalence relation if it satisfies three critical properties: it must be reflexive (aRa for all a in A), symmetric (if aRb then bRa), and transitive (if aRb and bRc then aRc). A failure in any one of these means it is not an equivalence relation. For functions, an Injective (one-to-one) function means every element in the domain maps to a unique, distinct element in the codomain. A Surjective (onto) function means every element in the codomain has at least one pre-image in the domain. A function that is both injective and surjective is called Bijective. Bijective functions are especially important because they are the only functions that have a well-defined inverse.

Common Error

A common trap is assuming that a relation is reflexive just because it is symmetric and transitive. Reflexivity must be checked for EVERY element in the base set A. If even one element 'x' does not relate to itself (xRx), it is not reflexive.

How to Avoid

Always double-check your initial assumptions before calculating.

Worked Example

Q: Let A = {1, 2, 3}. Consider the relation R = {(1,1), (2,2), (3,3), (1,2), (2,1)}. Is this relation an equivalence relation?

Steps:

  • Check Reflexive: Are (1,1), (2,2), and (3,3) in R? Yes.
  • Check Symmetric: For every (a,b), is (b,a) in R? We have (1,2), and (2,1) is also there. Yes.
  • Check Transitive: For (1,2) and (2,1), is (1,1) present? Yes. Are there any other chains? No.
  • Since it satisfies all three properties, it is an equivalence relation.

Solution

Yes, it is an equivalence relation.

Exam Pattern

ERB exams often present a relation defined mathematically, such as 'x - y is an even integer'. You must mentally test the three conditions. Hint: standard divisibility relations are almost always equivalence relations.

PYQ Focus

Identifying whether a relation is an equivalence relation (reflexive, symmetric, transitive) is a classic 1-mark question. Examiners love to test the boundaries of these definitions.

Quick Review

  • Equivalence = Reflexive + Symmetric + Transitive.
  • Reflexive: every element to itself.
  • Injective = One-to-one mapping.
  • Surjective = Onto mapping (codomain equals range).
  • Bijective functions have inverses.
