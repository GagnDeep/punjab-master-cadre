Linear Inequalities & Mathematical Reasoning

Objectives

  • Solve absolute value (modulus) inequalities.
  • Understand graphical regions represented by linear inequalities.
  • Determine the negation, converse, and contrapositive of logical statements.
  • Identify tautologies and fallacies using truth tables.

Core Concept

When solving inequalities, remember the golden rule: multiplying or dividing by a negative number flips the inequality sign. For absolute value (modulus) inequalities, |x| < a translates to -a < x < a. Conversely, |x| > a translates to x < -a OR x > a. In Mathematical Reasoning, a statement 'If p, then q' (p → q) has three important related statements. The Converse is 'If q, then p' (q → p). The Inverse is 'If not p, then not q' (~p → ~q). The Contrapositive is 'If not q, then not p' (~q → ~p). A crucial fact for the exam is that a statement is logically equivalent ONLY to its contrapositive. A Tautology is a statement that is always true, regardless of the truth values of its components.

Common Error

A common logical trap is assuming that the converse of a true statement is also true. For example, 'If it is a dog, it is an animal' is true, but the converse 'If it is an animal, it is a dog' is false. Only the contrapositive holds the same truth value.

How to Avoid

Always double-check your initial assumptions before calculating.

Worked Example

Q: Find the contrapositive of the statement: 'If a number is divisible by 9, then it is divisible by 3.'

Steps:

  • Identify the hypothesis (p): 'A number is divisible by 9.'
  • Identify the conclusion (q): 'It is divisible by 3.'
  • The format is p → q.
  • The contrapositive format is ~q → ~p.
  • Write ~q: 'A number is NOT divisible by 3.'
  • Write ~p: 'It is NOT divisible by 9.'
  • Combine: 'If a number is NOT divisible by 3, then it is NOT divisible by 9.'

Solution

If a number is not divisible by 3, then it is not divisible by 9.

Exam Pattern

They frequently test modulus inequalities with quadratics inside, e.g., |x2 - 4| < 5. You must split this into -5 < x2 - 4 < 5, solve the two parts separately, and find the intersection.

PYQ Focus

Graphical solutions to inequalities and questions testing the contrapositive of a statement are staple questions. These are pure logic and can be solved very quickly.

Quick Review

  • Flip the inequality sign when multiplying/dividing by a negative.
  • |x| < a means -a < x < a.
  • Contrapositive of (p → q) is (~q → ~p).
  • A statement is logically equivalent to its contrapositive.
  • Tautology = Always True; Fallacy = Always False.
