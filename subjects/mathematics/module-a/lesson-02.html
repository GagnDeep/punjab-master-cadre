Lesson 02: Types of Relations & Functions

ਸੰਬੰਧਾਂ ਅਤੇ ਫੰਕਸ਼ਨਾਂ ਦੀਆਂ ਕਿਸਮਾਂ

Why this matters (ERB 2022 Pattern)

Identifying whether a relation is an equivalence relation (reflexive, symmetric, transitive) is a classic 1-mark question. Examiners love to test the boundaries of these definitions.

ਇੱਕ ਸੰਬੰਧ ਬਰਾਬਰੀ (equivalence) ਹੈ ਜਾਂ ਨਹੀਂ, ਇਹ ਪਛਾਣਨਾ ਆਮ ਤੌਰ 'ਤੇ 1 ਨੰਬਰ ਦਾ ਸਵਾਲ ਹੁੰਦਾ ਹੈ। ਪ੍ਰੀਖਿਅਕ ਇਹਨਾਂ ਪਰਿਭਾਸ਼ਾਵਾਂ ਦੀਆਂ ਸੀਮਾਵਾਂ ਦੀ ਜਾਂਚ ਕਰਨਾ ਪਸੰਦ ਕਰਦੇ ਹਨ।

By the end of this lesson, you will:

  • Identify reflexive, symmetric, and transitive relations with ease.
  • Understand the concept of an equivalence relation.
  • Define one-to-one (injective) and onto (surjective) functions.
  • Determine if a function is bijective by checking both conditions.
  • Calculate composite functions quickly.

Core Concepts and Exam Focus

A relation R on a set A is an equivalence relation if it satisfies three critical properties: it must be reflexive (aRa for all a in A), symmetric (if aRb then bRa), and transitive (if aRb and bRc then aRc). A failure in any one of these means it is not an equivalence relation. For functions, an Injective (one-to-one) function means every element in the domain maps to a unique, distinct element in the codomain. A Surjective (onto) function means every element in the codomain has at least one pre-image in the domain. A function that is both injective and surjective is called Bijective. Bijective functions are especially important because they are the only functions that have a well-defined inverse.

Equivalence classes form a partition of the base set. This means that if you have an equivalence relation on a set, it divides the set into non-overlapping subsets where every element belongs to exactly one subset, and elements within the same subset are related to each other. For example, the relation "modulo n" on integers partitions them into n distinct equivalence classes.

Let's delve deeper into function properties. To prove a function is injective, you typically start by assuming f(x1) = f(x2) and mathematically demonstrating that this necessitates x1 = x2. To prove it is surjective, you must show that for every 'y' in the codomain, there exists an 'x' in the domain such that f(x) = y. Exam questions often ask you to identify the domain or range of complex rational or radical functions to determine surjectivity. Always check for values that make the denominator zero or the expression under an even root negative.

Composite functions, denoted as f(g(x)) or (f o g)(x), require careful attention to domains. The domain of f o g is the set of all x in the domain of g such that g(x) is in the domain of f. A classic exam trap is to calculate the algebraic formula for f(g(x)) and then find its domain, which can lead to incorrect answers because it might hide the original restrictions of g(x). Always evaluate the inner function's restrictions first.

Inverse functions, f-1(x), conceptually reverse the mapping of f. Geometrically, the graph of an inverse function is the reflection of the original function across the line y = x. This property is highly useful for solving graphical problems quickly.

Finally, we must understand the difference between explicit and implicit functions. An explicit function is written as y = f(x), while an implicit function is given as a relation between x and y, like x2 + y2 = 25. While you can sometimes rearrange implicit equations to solve for y explicitly, it's not always possible or efficient. You will learn techniques to work with these directly in the calculus module.

Worked Example

Q: Let A = {1, 2, 3}. Consider the relation R = {(1,1), (2,2), (3,3), (1,2), (2,1)}. Is this relation an equivalence relation?

Step 1: Check Reflexive: Are (1,1), (2,2), and (3,3) in R? Yes.

Step 2: Check Symmetric: For every (a,b), is (b,a) in R? We have (1,2), and (2,1) is also there. Yes.

Step 3: Check Transitive: For (1,2) and (2,1), is (1,1) present? Yes. Are there any other chains? No.

Step 4: Since it satisfies all three properties, it is an equivalence relation.

Answer: Yes, it is an equivalence relation.

🧠 How ERB Asks It

ERB exams often present a relation defined mathematically, such as 'x - y is an even integer'. You must mentally test the three conditions. Hint: standard divisibility relations are almost always equivalence relations.

Quick Recap

  • Equivalence = Reflexive + Symmetric + Transitive.
  • Reflexive: every element to itself.
  • Injective = One-to-one mapping.
  • Surjective = Onto mapping (codomain equals range).
  • Bijective functions have inverses.

ਸਭ ਤੋਂ ਪਹਿਲਾਂ, ਇੱਕ ਸੰਬੰਧ 'Equivalence' ਕਦੋਂ ਹੁੰਦਾ ਹੈ? ਜਦੋਂ ਇਹ ਤਿੰਨ ਸ਼ਰਤਾਂ ਪੂਰੀਆਂ ਕਰੇ: Reflexive, Symmetric, ਅਤੇ Transitive. Reflexive ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਹਰ ਚੀਜ਼ ਦਾ ਆਪਣੇ ਆਪ ਨਾਲ ਸੰਬੰਧ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ। ਜਿਵੇਂ ਸ਼ੀਸ਼ੇ ਵਿੱਚ ਆਪਣਾ ਅਕਸ ਦੇਖਣਾ। Symmetric ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਜੇਕਰ A ਦਾ B ਨਾਲ ਸੰਬੰਧ ਹੈ, ਤਾਂ B ਦਾ ਵੀ A ਨਾਲ ਸੰਬੰਧ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ। ਜਿਵੇਂ ਦੋਸਤੀ! ਜੇਕਰ ਮੈਂ ਤੁਹਾਡਾ ਦੋਸਤ ਹਾਂ, ਤਾਂ ਤੁਸੀਂ ਵੀ ਮੇਰੇ ਦੋਸਤ ਹੋ। Transitive ਥੋੜ੍ਹਾ ਟ੍ਰਿਕੀ ਹੈ: ਜੇਕਰ A ਦਾ B ਨਾਲ ਸੰਬੰਧ ਹੈ, ਅਤੇ B ਦਾ C ਨਾਲ, ਤਾਂ A ਦਾ C ਨਾਲ ਸੰਬੰਧ ਹੋਣਾ ਜ਼ਰੂਰੀ ਹੈ।

ਹੁਣ ਫੰਕਸ਼ਨਾਂ ਦੀ ਗੱਲ ਕਰੀਏ। ਪ੍ਰੀਖਿਆ ਵਿੱਚ ਤੁਹਾਨੂੰ Injective ਅਤੇ Surjective ਸ਼ਬਦ ਬਹੁਤ ਦਿਖਣਗੇ। Injective ਦਾ ਮਤਲਬ ਹੈ One-to-one, ਯਾਨੀ ਹਰ ਇੱਕ ਲਈ ਇੱਕ ਵੱਖਰਾ ਨਤੀਜਾ। Surjective ਦਾ ਮਤਲਬ ਹੈ Onto, ਯਾਨੀ ਕੋਈ ਵੀ ਨਤੀਜਾ ਖਾਲੀ ਨਹੀਂ ਰਹਿਣਾ ਚਾਹੀਦਾ। ਜਦੋਂ ਇੱਕ ਫੰਕਸ਼ਨ ਇਹ ਦੋਵੇਂ ਸ਼ਰਤਾਂ ਪੂਰੀਆਂ ਕਰਦਾ ਹੈ, ਤਾਂ ਅਸੀਂ ਉਸਨੂੰ Bijective ਕਹਿੰਦੇ ਹਾਂ।

ਪ੍ਰੀਖਿਆ ਵਿੱਚ ਸਿੱਧੇ ਸਵਾਲ ਆਉਂਦੇ ਹਨ ਕਿ ਦਿੱਤਾ ਗਿਆ ਫੰਕਸ਼ਨ Bijective ਹੈ ਜਾਂ ਨਹੀਂ। ਇਹ ਧਿਆਨ ਰੱਖਣਾ ਕਿ ਸਿਰਫ਼ Bijective ਫੰਕਸ਼ਨਾਂ ਦਾ ਹੀ ਉਲਟ (inverse) ਸੰਭਵ ਹੁੰਦਾ ਹੈ। ਇਹ ਗੱਲ ਆਪਣੇ ਦਿਮਾਗ ਵਿੱਚ ਬਿਠਾ ਲਓ!

ਡੋਮੇਨ (Domain) ਅਤੇ ਰੇਂਜ (Range) ਕੱਢਣਾ ਬਹੁਤ ਧਿਆਨ ਨਾਲ ਕਰਨਾ ਚਾਹੀਦਾ ਹੈ। ਜਦੋਂ ਵੀ ਤੁਹਾਨੂੰ ਬਟੇ (fraction) ਵਿੱਚ ਕੋਈ ਫੰਕਸ਼ਨ ਦਿੱਤਾ ਹੋਵੇ, ਤਾਂ ਹਮੇਸ਼ਾ ਧਿਆਨ ਰੱਖੋ ਕਿ ਹੇਠਲਾ ਹਿੱਸਾ (denominator) ਕਦੇ ਵੀ ਜ਼ੀਰੋ ਨਹੀਂ ਹੋ ਸਕਦਾ। ਅਤੇ ਜੇਕਰ ਅੰਡਰਰੂਟ (square root) ਹੈ, ਤਾਂ ਉਸਦੇ ਅੰਦਰ ਵਾਲੀ ਰਕਮ ਕਦੇ ਨਕਾਰਾਤਮਕ (negative) ਨਹੀਂ ਹੋ ਸਕਦੀ। ਇਹ ਦੋ ਨਿਯਮ ਤੁਹਾਨੂੰ ਕਦੇ ਗਲਤੀ ਨਹੀਂ ਕਰਨ ਦੇਣਗੇ।
