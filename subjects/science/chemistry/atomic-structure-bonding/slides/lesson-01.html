Chemistry Module: Atomic Structure & Bonding

The "Address" of an Electron

  • n (Principal): Shell (Size/Energy) $\rightarrow 1, 2, 3...$
  • l (Azimuthal): Subshell (Shape) $\rightarrow 0, 1, 2...(n-1)$
  • m$_l$ (Magnetic): Orbital (Orientation) $\rightarrow -l$ to $+l$
  • m$_s$ (Spin): Spin direction $\rightarrow +\frac{1}{2}, -\frac{1}{2}$

Shapes of Orbitals

The Golden Rule

$ l < n $

If $n=2$, $l$ CANNOT be 2.
Thus, "2d" orbitals do not exist!

Counting Nodes (Zero Probability)

  • Angular Nodes: $l$
  • Radial Nodes: $n - l - 1$
  • Total Nodes: $(n - 1)$

Example: For a 3p orbital ($n=3, l=1$):
Angular = 1, Radial = 3-1-1 = 1. Total = 2.

Key Check for Invalid Sets

  • Is $l$ strictly less than $n$?
  • Is $m_l$ between $-l$ and $+l$?
  • Is $m_s$ exactly $+1/2$ or $-1/2$?
  • If YES to all $\rightarrow$ Valid Set!
