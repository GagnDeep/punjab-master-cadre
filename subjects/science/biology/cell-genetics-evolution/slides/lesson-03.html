Chargaff's Rules (Double-Stranded DNA)

  • Amount of Adenine = Thymine ($A = T$).
  • Amount of Guanine = Cytosine ($G = C$).
  • Therefore, $A + G = T + C$ (Purines = Pyrimidines).
  • Example: If $C = 20\%$, then $G = 20\%$. Remaining $60\%$ is $A+T$. So $A = 30\%$, $T = 30\%$.

The Central Dogma

The Golden Rule of Direction

All polymerases build new strands ONLY in the:

$5' \rightarrow 3'$

direction!

The Three RNAs in Translation

mRNA (Messenger)

Carries the genetic code (codons) from DNA to the ribosome.

tRNA (Transfer)

Brings specific amino acids. Contains the anticodon.

rRNA (Ribosomal)

Forms the core of the ribosome. Acts as a catalyst (ribozyme) to form peptide bonds.

Key Takeaways

  • $A+G = T+C$ in dsDNA.
  • DNA is read $3' \rightarrow 5'$, but built $5' \rightarrow 3'$.
  • RNA uses Uracil (U) instead of Thymine (T).
  • Transcription = Nucleus. Translation = Cytoplasm.
